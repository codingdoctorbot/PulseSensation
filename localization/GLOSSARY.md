## 4. Haptic Sensory & Motor Terminology

PulseHaptics uses specific tactile metaphors to describe sensory vibration patterns. Translators should preserve their evocative physical meaning:

| English Term | Concept / Tactile Meaning | Recommended deDE | Recommended frFR | Recommended esES / esMX |
| :--- | :--- | :--- | :--- | :--- |
| **Continuous texture** | A sustained sensation lasting as long as the state persists | Kontinuierliche Textur | Texture continue | Textura continua |
| **Bed** | The subtle baseline rumble underneath rhythmic impacts | Grundschwingung / Bett | Lit vibratoire | Lecho / Base continua |
| **Tactical flurry** | Rapid, dense sequence of multiple sharp pulses | Taktischer Pulssturm | Rafale tactique | Ráfaga táctica |
| **Mechanical snap** | Sharp, crisp high-frequency click | Mechanischer Schnapper | Déclic mécanique | Chasquido mecánico |
| **Mechanical detent** | Tactile notch felt when turning a physical wheel/knob | Mechanische Raste | Cran mécanique | Retén mecánico |
| **Thud** | Low-frequency, heavy physical impact | Dumpfer Schlag | Impact lourd / Sourde secousse | Golpe sordo / Impacto pesado |
| **Tick** | Brief, light high-motor click | Leichter Klick | Léger tic | Ligero chasquido / Tic |
| **Chime** | Pleasant, resonant high-motor burst | Helles Klingeln | Carillon cristallin | Campanilleo agradable |
| **Lub-dub** | Anatomical two-part heartbeat knock | Lub-Dub (Herzschlag) | Poum-poum (battement) | Lub-dub (latido) |
| **Envelope** | Attack, sustain, and decay of the vibration waveform | Hüllkurve | Enveloppe | Envolvente |
| **Low motor** | Heavy, slow rumble motor (left motor on standard gamepads) | Niedrigfrequenz-Motor (Schwer) | Moteur lent / lourd | Motor lento / pesado |
| **High motor** | Sharp, fast buzz motor (right motor on standard gamepads) | Hochfrequenz-Motor (Schnell) | Moteur rapide / aigu | Motor rápido / ligero |
| **Ramp** | Progressive escalation in vibration intensity | Intensitätsrampe | Rampe progressive | Rampa de intensidad |
